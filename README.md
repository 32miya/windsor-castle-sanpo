# ウィンザー城さんぽ

イギリス王室の城、ウィンザー城（バークシャー州ウィンザー）を、スマホで歩いて巡る3D散策。
世界さんぽシリーズ（サグラダ・ファミリアさんぽ・アトランティスさんぽ）と同じ操作系（three.js r128・単一HTML）。

- 城：下の郭（聖ジョージ礼拝堂・ホースシュー回廊・カーフュー・タワー・ヘンリー8世門・衛兵交代の行進）、中の郭（モットと円塔・200段の階段・ノルマン門）、上の郭（クアドラングル・チャールズ2世騎馬像・ジョージ4世門）、北テラス、東テラス庭園
- 内部：聖ジョージ礼拝堂（扇形ヴォールト・内陣とガーター騎士の旗・ジョージ6世記念礼拝堂）、ステート・アパートメント（大階段・ウォータールーの間・聖ジョージの間・ドールハウス・ガーターの玉座の間ほか）
- 円塔の上（戸口で「円塔に上る」→螺旋階段の演出→登塔の印）。旗は王室旗がなびく
- まわり：キャッスル・ヒルとハイ・ストリート、ヴィクトリア女王像、ギルドホール、テムズ川とウィンザー橋（白鳥・遊覧船）、対岸のイートンとイートン・カレッジ礼拝堂、ロング・ウォークの並木道と遠くのコパー・ホース
- とき：1348年（ガーター騎士団の創設。低い石の砦の円塔、下の郭の槍試合、円卓の館の土台、中世の町と市場、ウィンザーの森）／現在（2026年）
- 時刻：朝・昼・夕・夜（城の投光と窓の灯り）
- 見どころ札集め（全32か所・歩いて訪れたときだけ。localStorage `windsor_fuda`）、登塔の印（`windsor_seal`）、写真モード、道案内（光の矢印）、合成音（町・鐘・礼拝堂の和音・衛兵の行進曲）

建物や町並みは写真や資料をもとにした簡略な再現で、距離や大きさは歩きやすく縮めています。方角はおおむね実際どおり（北がテムズ川）。「1348年」は記録の少ない時代で、想像を含みます。
